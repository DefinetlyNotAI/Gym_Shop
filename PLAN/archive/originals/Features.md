For the site itself, I would think in terms of business features rather than pages.

For v1, these are the main features worth considering:

* Sales and promotions
  
  * Product discounts
  * Collection-wide discounts
  * Percentage discounts
  * Fixed-price discounts
  * Limited-time sales
  * Scheduled sale start/end
  * Automatic discounts
  * Coupon codes
  * Minimum-order requirements
  * Usage limits
  * First-order discounts

* Referral system
  
  * Unique referral code per customer
  * Referral link
  * Reward for referrer
  * Reward for referred customer
  * Referral history
  * Referral status
  * Anti-abuse checks
  * Reward only after completed/paid order
  * Optional referral tiers later

* Loyalty program
  
  * Points earned per purchase
  * Points balance
  * Redeem points for discounts
  * Bonus-point campaigns
  * Expiry rules
  * Order-based point history
  * VIP tiers later

* Product reviews
  
  * Star ratings
  * Written reviews
  * Verified purchase badge
  * Review moderation
  * Average rating per product

* Cart features
  
  * Persistent cart
  * Quantity editing
  * Variant editing
  * Discount code entry in checkout
  * Stock validation
  * Free-shipping progress indicator
  * Recommended add-ons
  * Cart expiry rules if needed

* Account features
  
  * Profile
  * Saved addresses
  * Order history
  * Referral code
  * Referral rewards
  * Loyalty points
  * Notification preferences
  * Account deletion

* Order features
  
  * Order confirmation
  * Order status
  * Shipment tracking
  * Invoice/receipt
  * Reorder
  * Support request tied to an order
  * Damaged-item replacement request

* Inventory features
  
  * Variant-level stock
  * Low-stock status
  * Out-of-stock status
  * Restock management
  * Stock adjustment history
  * Overselling prevention

* Shipping features
  
  * Multiple shipping methods
  * Shipping cost calculation
  * Free-shipping threshold
  * Estimated delivery date
  * Tracking number
  * Google map based location selection feature
  * Shipping zones
    * Inside Amman is a fixed cost
    * Outside Amman in a small area is a larger fixed cost
    * Else you have to pickup

* Customer support
  
  * General ticket
  * Order-related ticket
  * Damaged-product claim
  * Image upload
  * Replacement handling
  * Ticket status
  * Staff replies

* Marketing
  
  * Newsletter signup
  * Promotional banners
  * Featured products
  * Featured collections
  * New arrivals
  * Best sellers
  * First-order incentive
  * Referral campaigns
  * Loyalty campaigns

* Customer retention
  
  * Back-in-stock notifications
  * Price-drop notifications
  * Abandoned-cart emails
  * Reorder suggestions

* Search and discovery
  
  * Search inside shop/category/collection pages  
  * Filters
  * Sorting
  * Related products
  * Recently viewed products
  * Best sellers
  * Trending products

* Social features
  
  * Share product
  * Share referral link
  * Security and account protection

* Email verification
  
  * Password reset
  * Session management
  * Login rate limiting
  * Admin MFA
  * Suspicious-login detection
  * Audit logs for admin actions

* Store operations
  
  * Sales analytics
  * Revenue analytics
  * Conversion rate
  * Average order value
  * Top products
  * Referral performance
  * Coupon usage
  * Customer acquisition source
  * Low-stock alerts

For your type of store, I would prioritize these as the strongest v1 business features:

```text
Sales and coupon system
Referral codes and referral rewards
Loyalty points
Product reviews
Free-shipping threshold
Persistent cart
Order tracking
Damaged-item replacement support
Back-in-stock notifications
Newsletter
Basic sales analytics
Support for Arabic and English
```

For referrals specifically, I would keep it simple at first. Something like:

```text
Customer A referral code:
SHAHM5

Customer B uses SHAHM25:
5% off first order

After Customer B's order is paid:
Customer A receives 1% JOD store credit
```

That is much easier to manage than percentage commissions, cash payouts, or affiliate accounting.
